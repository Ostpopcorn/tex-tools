About TeX Tools

TeX Tools is a collection of tools for LaTeX files. The first one removes the comments of your files, or of all the files in a .zip or .tar.gz of your project, e.g., before you upload them to arXiv, where everybody can read them. The document stays the same: each step only removes what LaTeX would ignore anyway.
